Dad Athlete 92

A simple iPhone-friendly workout tracker for the 1 October to 31 December 2026 program.

Included
- Full 92-day daily tracker
- Foundation, Build and Athlete phases
- Push A, Pull A, Push B and Pull B
- Exact sets, rep ranges and rest times for every phase
- Weight, reps and RIR logging
- Exercise and day completion
- Nutrition, creatine and sleep checks
- Progress check-ins for weight and waist
- Local device saving through localStorage
- Offline support after first load

How to use on iPhone
1. Upload this folder to any static host, such as GitHub Pages, Netlify or Vercel.
2. Open the HTTPS address in Safari on your iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Open Dad Athlete from the Home Screen.

No account or database is required. Data stays in the browser on the device unless browser data is cleared.

Program note
1 October through 31 December 2026 is 92 calendar days.
